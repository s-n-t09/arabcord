ArabCord

واجهة Discord بالعربية

إضافة لعائلة Vendetta وRevenge وKettu لترجمة نصوص واجهة Discord إلى العربية. دعم RTL متاح حاليًا كخيار تجريبي ومغلق افتراضيًا.

فتح manifest.json

التثبيت

  1. انسخ رابط هذه الصفحة أو استخدم رابط الموقع المنشور من GitHub Pages.
  2. افتح Discord ثم اذهب إلى Settings → Plugins.
  3. اضغط على علامة + لإضافة Plugin جديد.
  4. الصق رابط Pages الأساسي ثم اضغط Install.
  5. وافق على التثبيت إذا ظهر تأكيد، ثم أعد تشغيل Discord.

تُستضاف ملفات التوزيع فقط على Pages: index.js وmanifest.json. لا يتم نشر src أو node_modules ضمن مخرجات الموقع.

الأمان والتحقق

يُبنى plugin داخل GitHub Actions بعد نجاح اختبارات الترجمة وفحص TypeScript. يتحقق workflow من أن SHA-256 الموجود في manifest يطابق الملف المبني، ثم ينشر المخرجات الموثقة فقط. لذلك يجب تثبيت plugin من رابط Pages الرسمي للمستودع، وليس من ملفات مجهولة أو روابط إعادة توجيه.

RTL التجريبي

الترجمة مفعّلة، أما RTL فهو خيار BETA مغلق افتراضيًا بسبب اختلاف بنية مكونات Discord بين الإصدارات. يمكن تفعيله يدويًا من إعدادات ArabCord مع العلم أنه تجريبي.

English

ArabCord is a Vendetta/Revenge/Kettu plugin that translates Discord’s interface into Arabic. RTL is currently experimental and disabled by default.

Install

  1. Copy this GitHub Pages URL.
  2. Open Discord and go to Settings → Plugins.
  3. Press + to add a plugin.
  4. Paste the Pages URL and press Install.
  5. Confirm the installation if prompted, then restart Discord.

Only generated distribution files are published to Pages: index.js and manifest.json. Source files and node_modules are not included in the published output.

Build security

GitHub Actions runs the translation tests and TypeScript check, verifies that the manifest SHA-256 matches the generated bundle, and publishes only the verified output. Install ArabCord only from the official Pages URL for the repository.
